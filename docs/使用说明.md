# GitHub 每日情报：使用说明

## 功能与数据边界

所有排名由 GitHub Trending、GitHub Search API、仓库 REST API 与本项目每日快照计算。AI 不参与线上排名；DeepSeek 已按当前计划留给本地版。

## 榜单

1. **今日全站热门**：GitHub Trending daily 候选，按页面的 `stars today` 降序。
2. **今日中文热门**：Trending 中文候选；README/简介去除代码和链接后，至少 40 个汉字且中文有效文本比例不低于 12%；按 `stars today` 降序。
3. **24h Star 增长**：当前 Star 减去前一个不同日期快照的 Star。首日显示“基线中”。
4. **24h Fork 增长**：当前 Fork 减去前一个不同日期快照的 Fork。首日显示“基线中”。
5. **AI 项目增长**：每天进行 4 次 GitHub Search：`topic:artificial-intelligence`、LLM、MCP、AI Agent；每次最多 100 条，原始候选上限 400。子类由仓库名称、简介、主题的规则识别；按真实 24h Star 增量排序。
6. **新项目爆发榜**：GitHub Search 查询近 5 天创建的仓库，最多 50 个候选；创建不超过 5 天。没有前日快照时以“总 Star / 项目年龄”估算；有快照后优先真实 24h Star 增量。
7. **自定义关键词增长**：预设词在 `config/keywords.json`。每词 GitHub Search 最多 25 个候选，按真实 24h Star 增量排序。当前预设为 Vue、Python、量化、爬虫。

## 每日候选数量

日报 JSON 的 `candidateCounts` 会记录当天每类实际候选数量，包括 Trending、AI、新项目与每个预设关键词。因为去重、API 失败和仓库已删除，实际数量可能小于查询上限。

## 文件

- `data/latest.json`：最新日报原始数据。
- `data/snapshots/YYYY-MM-DD.json`：每日 Star/Fork 快照，增长榜唯一依据。
- `data/history/index.json`：历史索引。
- `docs/history/YYYY-MM-DD.json`：网页可回看的日报。
- `config/keywords.json`：可维护的关键词和每词候选上限。

## 失败与安全

每次 API 请求最多重试 3 次。Trending 单来源失败会保留上一份成功来源数据；首日两来源都失败则不覆盖成功日报。Token 仅从 GitHub Actions Secret `GH_TOKEN` 注入，不写进仓库、网页、JSON 或日志。

## 本地 DeepSeek 阶段

下载项目到本地后，复制 `.env.example` 为 `.env` 并填写 `DEEPSEEK_API_KEY`。DeepSeek 只生成中文简介、AI 分类与谨慎的关注原因，不抓取数据、不参与排序。
